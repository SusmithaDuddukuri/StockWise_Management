# StockWise – Inventory & Warehouse Management

Fully functional static website for inventory, warehouse, purchase orders and stock tracking.

## Features
- Dashboard with stock stats & low-stock alerts
- Inventory list + 900 detailed item pages
- Purchase Orders, Suppliers, Warehouses, Stock Movements, Reports, Settings
- Working navigation, modals, forms, toasts, dark/light theme
- 500,000+ lines of code

## How to use
1. Extract the zip
2. Open `index.html` in a browser
3. Use the sidebar — all buttons and links work

Real-world domain: **Inventory & Warehouse Management System**.
